# EA Code Lab — starter website

A lightweight, responsive, static website starter for an MQL5 / Expert Advisor programming blog.

## What's included
- Home page
- Tutorials listing
- Three starter educational articles
- Services page
- About page
- Contact form that prepares an email in the visitor's email app
- Responsive navigation
- Basic page titles and meta descriptions
- No paid dependencies or build step

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a more realistic local preview, run a static server from this folder, for example:
   - Python: `python -m http.server 8000`
   - Then visit `http://localhost:8000`

## Before publishing
1. Open `assets/main.js`.
2. Replace `YOUR_EMAIL_ADDRESS_HERE` with the email address you want enquiries sent to.
3. Review the sample articles and test any code examples in MetaEditor before presenting them as verified.
4. Replace any sample claims, add your own bio, and check every page on mobile.
5. Add a privacy notice if you add analytics, mailing lists, tracking, or server-side forms.
6. Add a sitemap and `robots.txt` before launching, then register the site with Google Search Console.
7. Use your own domain when ready. Check current prices and renewal terms before purchasing.

## Free hosting path
A static site can be hosted on a suitable free static hosting plan, such as Cloudflare Pages. Follow the host's current instructions for deploying a static HTML project. Some workflows use a Git repository; keep a backup of the site files and avoid uploading credentials or private client code.

## Contact form limitation
This starter form does not send data to a server or store it. It opens the visitor's configured email application after you replace the placeholder email address. For a production form, choose a reputable form service or build a backend and add appropriate privacy and spam protections.
