MQL5 for Beginners: Understand the Building Blocks

An Expert Advisor is a program that runs in MetaTrader 5. Before adding trading rules, understand the basic event-driven structure and how to test changes safely.

Important: This is an introductory explanation, not a complete trading strategy. The examples below do not place orders.

1. The main event functions

Many Expert Advisors use three event functions:

  • OnInit() runs when the EA is initialised. Use it to prepare resources and validate inputs.
  • OnDeinit() runs when the EA is removed or shut down. Use it to release resources and clean up.
  • OnTick() runs when a new price tick arrives for the chart symbol. It is commonly used to evaluate current conditions.

2. A minimal example

#property strict

int OnInit()
{
   Print("EA initialised");
   return INIT_SUCCEEDED;
}

void OnDeinit(const int reason)
{
   Print("EA stopped. Reason: ", reason);
}

void OnTick()
{
   // Evaluate conditions here.
   // This example deliberately does not place trades.
}

This skeleton is useful for learning the lifecycle of an EA. It does not contain entry rules, position management, or risk controls.

3. Build in small steps

  1. Create a new Expert Advisor in MetaEditor.
  2. Add one small change at a time.
  3. Compile and read the first meaningful error if compilation fails.
  4. Use the Strategy Tester to inspect behaviour before considering live use.

4. What to learn next

After you understand the event functions, study input parameters, indicator handles, copying indicator buffers, symbol properties, order handling, and position/risk management. Learn each area independently before combining them.
